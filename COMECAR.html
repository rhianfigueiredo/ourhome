Vamos colocar seu app no ar.

Uma configuração inicial. Depois, é só entrar e registrar.

1. Publique os arquivos

Extraia o ZIP e envie o conteúdo da pasta para seu repositório ourhome, em Add file → Upload files. Confirme em Commit changes.

Em Settings → Pages, escolha Deploy from a branch → main → /(root) e salve. O arquivo index.html precisa estar na raiz do repositório.

O endereço esperado é rhianfigueiredo.github.io/ourhome/. Use o link que o GitHub mostrar após a publicação.

2. Prepare o banco compartilhado

Crie um projeto na sua conta do Supabase. Abra o SQL Editor, cole o conteúdo do arquivo abaixo e clique em Run.

Baixar arquivo SQL

3. Crie o acesso de vocês

No Supabase, abra Authentication → Users → Add user → Create new user. Crie uma conta para cada e-mail e marque Auto Confirm User.

  • Rhian: rhianfigueiredo@gmail.com

Use a senha inicial combinada na conversa. Ela será cadastrada no Supabase. Depois, cada pessoa pode alterá-la em Seu espaço → Alterar minha senha.

Mantenha o provedor Email habilitado e desative novos cadastros públicos (Allow new users to sign up).

4. Conecte o aplicativo

No botão Connect do seu projeto, copie a URL e a chave pública. Preencha abaixo para baixar seu config.js. Esta página só gera um arquivo no seu aparelho.

Use a chave pública. Chaves secret e service_role não são aceitas aqui.

Envie o config.js baixado ao mesmo repositório e substitua o arquivo anterior. Confirme em Commit changes e aguarde o GitHub atualizar a página.

5. Entrem e façam o primeiro registro

Abra o aplicativo, escolha seu nome e entre com a senha cadastrada. As despesas pessoais ficam no seu espaço; a casa é compartilhada em 50/50.

O novo banco começa vazio. Os registros da hospedagem anterior não são transferidos por este pacote.
